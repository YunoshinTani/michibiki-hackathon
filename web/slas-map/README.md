# GNSS ローカルモニター

QZ1 GNSS シリアルモニターをもとに、受信機の位置と測位情報をブラウザーに表示するローカルサイトです。NMEA解析は同梱の `gnss_core.py` が行います。

## 起動方法

1. Python 3 をインストールします。
2. 初回だけ `setup.bat` を実行します。
3. `start.bat` を実行します。
4. ブラウザーで `http://127.0.0.1:8765` を開きます。
5. GNSS受信機をUSB接続し、ポート一覧から `COM番号` を選び、通信速度を設定して「接続」を押します。標準値は `115200` baud です。

サイトはこのPC内 (`127.0.0.1`) だけで待ち受けます。終了するときは `start.bat` の黒い画面で Ctrl+C を押してください。

## 地図とデータ

地図ライブラリとOpenStreetMapの地図タイルをインターネットから読み込みます。GNSS受信と数値表示はローカルで動作します。地図タイルの読み込みに失敗した場合も、緯度・経度などの値は表示されます。

Fixが取れている位置をマーカーと軌跡で表示します。軌跡は接続中の最新500点をメモリー上に保持し、切断または再接続で消去します。位置や受信データはファイルや外部サービスへ送信しません。

バッテリー値には元スクリプトの注記どおり、機器の仕様で確認されていない推定値を `V*` として表示します。
