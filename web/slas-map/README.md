# GNSS ローカルモニター

QZ1 GNSS シリアルモニターをもとに、受信機の位置と測位情報をブラウザーに表示するローカルサイトです。NMEA解析は同梱の `gnss_core.py` が行います。

## 起動方法

1. Python 3 をインストールします。
2. 初回だけ `setup.bat` を実行します。
3. `start.bat` を実行します。
4. ブラウザーで `http://127.0.0.1:8765` を開きます。
5. GNSS受信機をUSB接続し、ポート一覧から `COM番号` を選び、通信速度を設定して「接続」を押します。標準値は `115200` baud です。

サイトはこのPC内 (`127.0.0.1`) だけで待ち受けます。終了するときは `start.bat` の黒い画面で Ctrl+C を押してください。

## 地図とデータ

地図ライブラリとOpenStreetMapの地図タイルをインターネットから読み込みます。GNSS受信と数値表示はローカルで動作します。地図タイルの読み込みに失敗した場合も、緯度・経度などの値は表示されます。

Fixが取れている位置をマーカーと軌跡で表示します。ローカル表示では、接続中の軌跡をメモリー上に保持し、次回接続時に新しい軌跡へ切り替えます。ローカル表示中は位置や受信データをファイルや外部サービスへ送信しません。

バッテリー値には元スクリプトの注記どおり、機器の仕様で確認されていない推定値を `V*` として表示します。

## Windows PC から学校サーバーへ送信

`send_gnss.py` はWindows PCのシリアルポート（既定: `COM16`、`115200` baud）からNMEAデータを読み、1秒ごとに最新状態をHTTPSで送ります。シリアル接続ごとに新しい記録を作り、Fix位置をサーバーへ追記します。起動例:

```bat
.venv\Scripts\python.exe send_gnss.py --url https://学校サーバー/公開パス/gnss_api.cgi?action=ingest
```

学校サイトのBasic認証ユーザー名とパスワードは起動時に入力します。認証情報はファイルに保存しません。位置情報を保護するため、送信先はHTTPSに限定しています。

COM16は同時に1つのプログラムしか開けません。送信中はローカル画面でCOM16を接続しないでください。

過去の接続記録は閲覧サイトの「表示する記録」から選択できます。経路の点数上限はありません。既存の `latest.json` があれば、残っている経路を初回アクセス時に「既存記録」として移行します。学校サーバーへの配置手順は [`server/README.md`](server/README.md) を参照してください。Python 2.7.5対応の受信CGIを`server/gnss_api.cgi`に用意しています。学校サーバーなどlocalhost以外で開くと、シリアル操作を隠した遠隔閲覧画面に自動で切り替わります。`?view=remote`を付けても同じです。
